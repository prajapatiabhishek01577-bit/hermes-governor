# Changelog

## 1.0.0 — 2026-09-13

- Initial portable package of Hermes Governor.
- Adds the native `hermes-governor` plugin, generic SOUL protocol append, minimal host patch, Windows installer, rollback path, and isolated tests.
- Built and validated against Hermes Agent 0.20.5 at commit `f377140e3ddb4c98a9e0b42c4497b8bb46ca697c`.
- Includes deferred-tool discovery support, final completion gates, non-coding verification continuation, and buffered streaming safeguards.
